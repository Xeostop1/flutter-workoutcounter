# 원형 후광 시안 v4 — 앱 미적용

승인된 v3의 캐릭터/눈 반사광/밝아질 때 웃는 표정/움직임은 유지하고, 뒤에 원형 후광만 추가한 확인용 시안입니다. v3 결과물은 덮어쓰지 않습니다.

## 결과

- `flame-preview-v4-halo.gif`: 400×400, 300프레임, 매20ms(50fps), 6초 무한 반복, 6,413,607 bytes.
- `preview-dim.png`: 은은한 짙은 붉은빛 후광.
- `preview-smile.png`: 밝은 주황·살구빛 가장자리와 따뜻한 금빛 중심의 후광.
- `render-preview.cjs`: 기존 v3 GIF를 읽고 캐릭터 뒤에 원형 그라데이션/부드러운 빛 번짐만 코드로 합성합니다. 캐릭터 이미지를 새로 생성하거나 얼굴을 다시 그리지 않습니다. 단순한 원형 조명이므로 새 image_gen 호출은 하지 않았습니다. 원래 캐릭터 생성 자료는 ../preview-v3/README.md에 있습니다.

캐릭터는 기존320px 크기를 유지하고 주변 여백만40px씩 늘렸습니다. 후광은 캐릭터 밝기와 같은 완만한 가속/감속으로 짙은 붉은색→붉은색→밝은 주황/금빛이 됐다가 자연스럽게 돌아옵니다.

## 검사

- 최종 GIF 프레임/각20ms/총6,000ms/무한 반복 확인.
- 원시 합성에서 불투명 캐릭터 RGB의 최대 차이0: 기존 얼굴·색·움직임을 보존했습니다. GIF 팔레트 인코딩 전 기준입니다.
- 후광 전용 위치의 RGB는 시작[37,19,25]에서 밝은 상태[219,124,89]로 증가했습니다.
- 같은 반지름의 상단/좌측 후광 색이 같아 원형 대칭임을 확인했습니다.
- 처음/끝 원시 RGB의 평균 차이는0.0185(0–255 범위)로 루프 경계에서 급격한 변화가 없도록 했습니다.
- 앱 GIF는 DB857400E95E6B9D3DFF6AEF120B51577A73D62DE28CA7184E3EEB112F1E6772, 앱 정지 PNG는 FB7233FC9F83D6CE00E14A50DC7332FE24100815F79A694B8A6C5C1781FC859B로 이전과 같습니다. 앱 코드/에뮬레이터/APK 설치는 하지 않았습니다.

재현: Node와 sharp가 있는 환경에서 `node design/login-flame/preview-v4/render-preview.cjs`. 시안만 검증했으며 실제 휴대폰/앱 재생은 확인하지 않았습니다. 앱 적용·용량 최적화는 사용자 확인 후 별도 작업입니다.
