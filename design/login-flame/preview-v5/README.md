# 크고 옅은 후광 시안 v5 — 앱 미적용

시안 제작/검사 완료. 승인된 v3의 캐릭터/표정/움직임을 그대로 두고, v4보다 큰 옅은 원형 후광을 합성했습니다. v3/v4 GIF와 앱 파일은 덮어쓰지 않았습니다.

- 후광 기준 반지름165→205px(약24% 확대), 최대 원판 불투명도0.85→0.40. 테두리도 더 넓게 부드럽게 번집니다.
- ‘캐릭터 아래쪽1/3’을 실제 몸 높이의 하단1/3로 해석했습니다. 해당 높이에 도달하기 전96px 구간에서 후광만 서서히 감추고 그 아래는 후광을0으로 만듭니다. 최초28px 페더는 수평 경계가 눈에 띄어96px로 넓혔습니다. 기준 높이는 캐릭터가 숨쉬듯 움직이는 동안 함께 따라갑니다. 캐릭터의 몸 자체는 감추거나 자르지 않습니다.
- 캐릭터는 기존320px 렌더링 크기를 유지합니다. 주변 여백만 늘려 출력은480×480입니다.
- 재현: `node design/login-flame/preview-v4/render-preview.cjs --large-soft`. 원형 조명 렌더러만 조정했으며 캐릭터 재생성/image_gen 호출은 하지 않았습니다.
